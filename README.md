# SahelVoice

Site et démo de SahelVoice : des enquêtes WhatsApp pour les ONG et les entreprises du Tchad,
avec des réponses écrites ou vocales transcrites par l'IA.

- Site (français) : https://toadoum.github.io/sahelvoice/
- Site (English) : https://toadoum.github.io/sahelvoice/en/
- Démo (dans le navigateur, sans inscription) : https://toadoum.github.io/sahelvoice/demo/

SahelVoice est un service de Quantum Qube Technologies, N'Djaména, Tchad.

Structure : `index.html` (FR), `en/index.html` (EN), `assets/site.css` et `assets/site.js` partagés,
`demo/` (démo en français).
